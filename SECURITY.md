# Security Policy

## Supported versions

Security fixes are made against the active development branch. Older snapshots may not receive security updates.

## Reporting a vulnerability

Please do not publish suspected vulnerabilities in public issues or discussions.

If GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security → Advisories → Report a vulnerability** flow. Otherwise, contact the repository owner privately through GitHub and include:

- A concise description of the affected area.
- The steps needed to reproduce the issue, using only accounts and data you own or are authorized to test.
- The potential impact and any suggested mitigation.

Do not include real users' personal data, credentials, API keys, or other secrets in a report.

## Response expectations

This is an independently maintained project, so response times are not guaranteed. Please allow reasonable time for triage and coordinated disclosure. Do not access, modify, or retain data belonging to other users while investigating a suspected issue.
